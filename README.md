# 🚲 Rent a Bike

A responsive bike rental website that allows users to explore bikes, search for rental options, apply filters, and manage their bookings through a simple and user-friendly interface.

## 📌 About the Project

Rent a Bike is a front-end web application designed to make the bike rental process simple and convenient. Users can choose their pickup and drop-off locations, select rental dates and times, browse different types of bikes, and place booking orders.

The website also includes user authentication demo screens, multiple themes, coupon functionality, and payment method selection.

## ✨ Features

- **Bike Search:** Select pickup district, pickup location, drop-off location, and rental dates.
- **Bike Catalog:** Browse available bike options.
- **Bike Filters:** Filter bikes by type and transmission.
- **Price Sorting:** Sort bikes by price or name.
- **Booking System:** Place orders and view bookings.
- **Coupon Code:** Apply the `WELCOME10` coupon code.
- **User Authentication:** Sign-up and sign-in demo functionality.
- **Theme Selection:** Switch between Light, Dark, and Ocean themes.
- **Payment Options:** Select UPI, Card, or Pay at Pick-up.
- **Contact Form:** Submit messages through the contact section.
- **Responsive Design:** Designed for a user-friendly browsing experience.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure `index.html`, `style.css`, `script.js`, and the `images` folder are present.
4. Open `index.html` in your browser, or run it using the Live Server extension in VS Code.

## 🎮 How to Use

1. Open the website.
2. Select your pickup and drop-off locations and rental dates.
3. Browse the bike catalog and apply filters or sorting.
4. Select a bike and follow the booking process.
5. View your bookings in the My Bookings section.

## ⚠️ Notes

- This project uses HTML, CSS, and JavaScript for front-end functionality.
- User accounts are intended for demo use and are stored in the browser, as indicated in the interface.
- Booking and payment features should not be considered a production-ready rental or payment service.
- Actual payment processing and secure backend integration are not established by the provided HTML code.

## 🎯 Project Objective

The objective of this project is to build a user-friendly bike rental website and practice front-end web development, form handling, filtering, sorting, and interactive UI design.
